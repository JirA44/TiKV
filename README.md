# TiKV — base clé-valeur distribuée / Distributed Key-Value Database

## Français

TiKV est une base clé-valeur transactionnelle distribuée conçue pour stocker des données sur plusieurs nœuds avec réplication.

### À quoi ça sert ?

Elle peut fournir du stockage à des applications qui doivent répartir les données et rester disponibles en cas de défaillance d’un nœud.

### Exemple

Dans un environnement de test, lire et écrire des clés via un client TiKV, puis examiner transactions et réplication.

Ce dépôt contient un README minimal. Consulter la documentation officielle avant installation.

## English

TiKV is a distributed transactional key-value database designed to store data across multiple replicated nodes.

### What is it for?

It can provide storage for applications that need to partition data and remain available when a node fails.

### Example

In a test environment, read and write keys through a TiKV client, then inspect transactions and replication.

This repository has a minimal README. Consult the official documentation before installing.
